# apk-release

Android 测试包存放仓库。

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `test.apk` | 42 MB | 测试安装包 |

## 下载

私有仓库需要用已登录的账号访问，或先运行：

```bash
gh release download -R nanslarf/apk-release
```

如需公开分享链接，把仓库可见性改为 public：

```bash
gh repo edit nanslarf/apk-release --visibility public --accept-visibility-change-consequences
```
